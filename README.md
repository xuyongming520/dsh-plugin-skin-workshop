# 皮肤工坊 · Skin Workshop

给 DSH 换皮肤：换背景壁纸、换主题风格、调面板材质与阅读遮罩，自由组合，整套保存或分享给同事。
**不联网、不上传**：壁纸只在本机压缩，皮肤只存在你自己的浏览器里。

## 安装

要求 **DSH 0.2.2-rc.1 及以上、0.3.0 以下**（插件声明里写死的兼容范围）。

在 DSH 的「添加插件」输入框里粘贴仓库地址：

```
https://github.com/xuyongming520/dsh-plugin-skin-workshop
```

允许授权提示，装完按 `Cmd + R` 刷新。之后左侧栏和「设置」里都会出现**皮肤工坊**。

更新时把同一个地址再粘贴一次安装即可；已保存的皮肤和壁纸不会丢失。也可以下载 `.tgz` 解压成文件夹，把文件夹绝对路径粘进同一个输入框（这种方式是软链接安装，文件夹不能移动）。

## 快速上手

1. 打开左侧「皮肤工坊」。第一次进来是干净的空白起步，中间就是上传入口。
2. 把 PNG / JPEG / WebP 拖进虚线框，或点一张内置背景。**选好立刻生效**，不用再点保存。
3. 想换界面风格，切到「换主题」，四张卡片可以直接比；每张卡片的「套用配套」会连背景和材质一起换。
4. 觉得壁纸太抢戏或太通透，调「正文阅读遮罩」，或直接点「更通透 / 更清晰」。
5. 满意后到底部的「保存与分享」：**保存到我的皮肤**，或**导出分享包**发给别人。

改错了不用慌：每次即时生效后，提示条右侧有「撤销」，一步回到上一个外观；顶部右侧还有「恢复默认」。

## 三块分别控制什么

| 区域 | 控制内容 | 不会顺带改变 |
| --- | --- | --- |
| 换皮肤 · 背景 | 自己的图片、原创内置背景、无背景；壁纸浓淡与铺放（在「高级」里） | 主题、面板与阅读遮罩 |
| 换皮肤 · 阅读 | 正文阅读遮罩；一键「更通透 / 更清晰」；面板材质与磨砂（在「高级」里） | 主题与壁纸 |
| 换主题 | 原生、现代简约、XP 复古、像素方块；配色与控件形状 | 壁纸、材质、阅读遮罩、名称 |

- **原生风格**：不覆盖宿主任何主题 token，读取当前配色；保留原生圆角、边框、控件阴影与发送按钮形状，此时圆角/描边/阴影不可编辑。适合「只换背景」。
- **现代简约**：原「玻璃壁纸」的控件风格，内部 id `glass` 保留以兼容旧数据。
- **XP 复古 / 像素方块**：风格化原创实现，不是 Windows 或游戏原界面的复刻，同样可以搭配自己的照片与玻璃材质。
- **快速搭配**：在「我的皮肤」页签里，四个完整起点（只换背景、简约玻璃、XP 复古、像素方块），载入即生效。

## 为什么有三种“不透明度”

| 调节项 | 含义 |
| --- | --- |
| 壁纸不透明度 `0–100%` | 只让图片向当前主题底色淡出；0% 看不到图片，100% 保留原图浓度 |
| 面板不透明度 `0–100%` | 侧栏、输入框与气泡等面板的填充；越低越透，磨砂单独调 |
| 正文阅读遮罩 `0–100%` | 正文区域的独立底板；浅色提亮、深色压暗，不带动侧栏和输入框 |

三者互不联动。不透明面板只关闭面板透光与磨砂，正文遮罩仍可独立调节。

遮罩低于 30% 时会提醒复杂壁纸上的小字可能发花——这是允许你自主选择的取舍，**低遮罩不保证文字对比度**。日常 40% 左右壁纸清楚、字也能读；长时间纯阅读可以点「更清晰」。插件页滚动时的吸顶标题会跟随阅读遮罩（遮罩 + 10%，下限 40%），不会变成一条白带。

## 保存与分享

- **即时生效**：上传壁纸、点内置背景、切主题、套用配套、拖阅读遮罩或高级滑杆，都会立刻应用到真实界面（滑杆有 300ms 防抖）。
- **当前外观 vs 我的皮肤**：正在用的这套外观单独存放，不占「我的皮肤」的槽位；只有点「保存到我的皮肤」才会进收藏。删除已保存的皮肤不会改变当前外观，想回默认用顶部「恢复默认」。
- **试穿 60 秒**：临时预览，不写存储，到时自动恢复，右下角可提前结束。
- **分享**：导出为 `.dsh-skin.json`，对方在「我的皮肤 → 导入分享包」里导入即可，导入只进编辑器、不自动应用。图片随包嵌入，不依赖本机路径。分享前确认图片内容和使用权限。
- 收藏上限 16 款，并有本地总容量保护；保存失败会报错，不会谎报成功。

## 数据格式与兼容

- 皮肤包为 `format: "dsh-skin-workshop"`、`version: 2`，显式保存 `readingOpacity` 与 `wallpaper.opacity`。
- **继续读取 v1 包与旧本地库**：旧库只在内存中规范化，启动不写回，明确保存时才升级为 v2；旧名称、图片、id 与已应用快照全部保留。
- 物理存储键仍是 `dsh.skin-workshop.library.v1`，文档版本可以是 1 或 2。

## 数据与安全边界

- 所有图片在浏览器本地处理，无遥测、无上传接口、无外部资源请求。
- 壁纸上传仅 PNG、JPEG、WebP；原图最多 10 MiB / 3200 万像素 / 单边 12000px；重编码最长边 1920px，复杂大图继续缩小。WebP 动画会静态化。
- 内嵌图片不超过 720,000 字符；单个导入包最多 1,100,000 bytes；库 JSON 最多 2,100,000 字符。同源其他插件的数据也占浏览器配额。
- 皮肤包是严格校验的数据，未知字段、任意 CSS / JavaScript / hooks、SVG、远程图片地址、第三方主题格式一律拒绝。v1/v2 分别校验，不用“填默认值”掩盖损坏的 v2 字段。
- 损坏旧库不会静默删除；下一次成功保存前备份到 `dsh.skin-workshop.recovery.v1`，已有不同备份则停止写入。
- 恢复默认遇到存储故障时仍先清除当前窗口效果，并提示刷新可能恢复旧设置。
- 数据只在当前浏览器 / 设备 / 页面源中保存，不跨设备同步。清理站点数据前请导出。

## 覆盖范围与限制

适配 DSH `0.2.2-rc.1` / DS Bot `0.3.2` 的现有主题、插槽与 DOM 结构。React 和宿主模块通过 peerDependencies 由宿主提供，不重复打包运行库。

- 壁纸在整窗底层；适配原生侧栏、插件页标题、原生会话、DS Bot 左侧栏、标题胶囊、聊天气泡和输入框等。
- 每个大面板只画一层材质，原生侧栏内部不重复叠色；吸顶标题的背板跟随正文遮罩。
- 模糊不放在原生布局祖先上；装饰背板和实际卡片负责模糊，避免改变窗口标题栏和浮层的 fixed 定位。
- 不改布局尺寸、导航位置、窗口拖动区、按钮功能、发送逻辑、状态色或原生强调色；DS Bot 平铺消息模式不会被强制改成气泡。
- 第三方页面、iframe 有自己的样式或文档，不保证整套适配。不要同时开多个全局换肤插件。
- 示例是效果示意，不是用户聊天截图；与实际窗口比例不同，背景裁切和原生配色可能不同。整屏明暗始终跟随 DSH。
- 暂不增加动态/视频壁纸、多图轮播、远程图地址、音乐/歌词、字体上传、任意 CSS、在线市场或账户同步。这轮优先把静态背景与主题的组合做顺。
- 选择器是版本兼容层，不是永久稳定 API，DSH / DS Bot 大版本更新应复测。

## 实现参考

仅参考思路，不安装或复制第三方成品：

- [lsaa4/dsh-custom-ui](https://github.com/lsaa4/dsh-custom-ui)：整窗壁纸与玻璃氛围。
- [HaoyueQin/deepseek-harness-background](https://github.com/HaoyueQin/deepseek-harness-background)：壁纸浓淡、阅读保护、面板与模糊分开调，阅读遮罩适配明暗模式。

实现仍是我们自己的数据格式、材质适配层、60 秒可撤回试穿和壁纸随包分享，不修改 DSH 或其他插件。

## 开发与验证

```text
violet-skin/
├── package.json / cordis.patch.yml    # 身份、版本与安装接线
├── index.js                          # 空 Host 载具，无网络接口
├── client.js                         # 自动生成的浏览器模块
├── src/
│   ├── model.js                      # 独立主题/组合、v1/v2 格式与严格校验
│   ├── backgrounds.js                # 原创内置背景
│   ├── renderer.js                   # 原生/自定义主题与独立材质变量
│   ├── store.js                      # 本地库、应用快照与试穿计时
│   ├── files.js                      # 图片压缩、导入/导出
│   ├── ui-style.js / ui.js            # 组合库、两块编辑区与示意
│   └── plugin.js                     # 插槽注册、浮条、资源清理
├── scripts/build.mjs                 # 无第三方依赖的受限 ESM 封装器
├── examples/                         # 旧 v1 样例 + v2 背景搭配
├── tests/                            # 单测、组合编辑与原生壳浏览器回归
└── locale/                           # 插件元数据
```

不要手改生成客户端：

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
node tests/workshop.browser.mjs
node tests/native-shell.browser.mjs
```

浏览器测试需设置 `DSH_TEST_PLAYWRIGHT` 和 `DSH_TEST_REACT_DIR`（React / ReactDOM / Scheduler 本地测试副本）。可选 `DSH_TEST_ARTIFACT_DIR` 输出截图，`DSH_TEST_HOST_REFERENCE_DIR` 使用从当前安装 DSH 解出的完整原生 CSS；不提供时使用随包精简 fixture。

验证覆盖独立组合、只换背景时的原生配色/几何、三种不透明度、原生明暗/悬停按钮、fixed/标题栏定位、滚动标题、截图壁纸像素、黑/白壁纸上的默认阅读对比度、旧包/旧库采用、配额异常、试穿回退、清理、窄屏和减少动效。

**这些是真实 React + Chromium 的隔离宿主测试，不等于已登录桌面集成验证。** 不读取真实用户的 localStorage 或会话。安装目录是工作区的链接包时，重建客户端后刷新既有 DSH 页面即可；未验证宿主开发 watcher，不承诺 HMR。
